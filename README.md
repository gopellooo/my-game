# FPV Flight Lab

Мобильный FPV-тренажёр. Два стика, режимы Angle и Acro, взлёт, зависание, шесть ворот и посадка.

Откройте index.html через статический HTTP-сервер. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Физика упрощена. Экранные стики не заменяют практику с пультом.
